# Python Banking System

## Overview
This project is a simple Banking System developed using Python. It simulates basic banking operations and provides a menu-driven interface for users to manage their accounts.

## Features
- **Create Account:** Register a new account with a unique username and password.
- **Login Authentication:** Verify user credentials before accessing banking services.
- **Deposit Money:** Add money to the account balance.
- **Withdraw Money:** Withdraw money from the available balance.
- **Balance Management:** Track and update the account balance.
- **Interactive Menu:** Navigate between banking operations through a simple menu.

## Technologies Used
- Python 3

## Concepts Applied
- Variables and Data Types
- Lists and Dictionaries
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`while`)
- Functions
- User Input and Output

## How to Run
1. Clone or download this repository.
2. Open the project in your Python IDE.
3. Run the Python file.
4. Follow the instructions displayed in the terminal.

## Project Purpose
This project was developed as a practical application of Python programming fundamentals, focusing on problem-solving, data management, and implementing basic banking operations.
